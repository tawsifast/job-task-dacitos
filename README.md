## About

**Amaze Property Management Solutions Pvt Ltd (AmazePMS)** is a premier integrated property management company under the **ACTION GROUP of Companies**, founded in **2001** by **Mr. Subhani Abdul** — an Indian Navy veteran and Certified Security Practitioner.

We deliver end-to-end property management services across India, managing **20M+ sq. ft.** of commercial and residential space with a workforce of **15,000+ in-house trained professionals** — no subcontractors.

**Certifications:** ISO 9001:2015, ISO 14001:2015, OHSAS 18001, NSR Certified Security Services

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start development server |
| `npm run build` | Production build |
| `npm run start` | Start production server |
| `npm run lint` | Run ESLint |

## Project Structure

```
src/
├── app/                          # Next.js App Router pages

│   ├── contact/
│   ├── gallery/
│   ├── our-clients/
│   ├── our-strength/

│   ├── services/

│   ├── layout.js                 # Root layout
│   └── page.js                   # Home page
├── components/                   # Reusable React components
│   ├── Hero.jsx                  # Animated hero carousel
│   ├── Navbar.jsx                # Fixed navigation bar
│   ├── TopContactBar.jsx         # Top contact info bar
│   ├── Footer.jsx                # Site footer
│   ├── PageBanner.jsx            # Inner page banners
│   ├── SocialFloatingBar.jsx     # Floating social icons

    └── siteData.js               # Site-wide content & config
```
